# Run_WLO — Wake-on-LAN セットアップ & 実行ツール

外出先から自宅PCを遠隔起動(WOL: Wake-on-LAN)できるようにするためのリポジトリです。
[計画スプレッドシート](https://docs.google.com/spreadsheets/d/1-stNXkUkWBJkvtsxiLp512gW5FvUrN4RXpKdJj8NxeI/edit)の6ステップに沿って構成しています。

## 収録物

| ファイル | 内容 |
| --- | --- |
| `wol.py` | マジックパケット送信スクリプト(Python 3 標準ライブラリのみ、追加インストール不要) |
| `devices.example.json` | 起動対象PCの登録ファイルの雛形。`devices.json` にコピーして使う |

## クイックスタート(中継端末・LAN内のPCから)

```bash
# MACアドレスを直接指定
python3 wol.py 00:11:22:33:44:55

# デバイスを登録して名前で起動
cp devices.example.json devices.json   # 中身を自分のPCのMACに書き換える
python3 wol.py --device desktop-pc

# 登録済みデバイスの一覧
python3 wol.py --list
```

> `devices.json` は自宅のMACアドレス等を含むため、Git管理対象外(`.gitignore`済み)です。

## セットアップ手順(スプレッドシートの6ステップ)

### ステップ1: 事前確認 — MACアドレスの確認(ターゲットPC)

- **Windows**: コマンドプロンプトで `ipconfig /all` を実行し、有線LANアダプターの「物理アドレス」(例: `00-11-22-33-44-55`)をメモ。
- **Mac/Linux**: `ifconfig` または `ip link` で確認。
- ✅ 完了目安: 12桁のMACアドレスが手元に控えてある。

> **注意**: WOLは基本的に**有線LAN**で使う機能です。Wi-Fiアダプターは対応していないことが多いので、有線接続のアダプターのMACを控えてください。

### ステップ2: BIOS/UEFI設定(ターゲットPC)

1. PC起動直後に F1 / F2 / Del キー等を連打してBIOS/UEFI画面に入る。
2. 「Power」や「Advanced」メニューから **Wake on LAN** / **Preboot Wake On LAN** / **Power On by PCI-E** などの項目を **Enabled** にする。
3. 設定を保存して再起動。
4. ✅ 完了目安: BIOS設定が保存され、シャットダウン中もLANポートのリンクランプが点灯している。

### ステップ3: OSネットワーク設定(ターゲットPC)

Windowsの場合:

1. デバイスマネージャー → ネットワークアダプター → 対象アダプターのプロパティを開く。
2. 「電源の管理」タブで以下をすべてオンにする:
   - このデバイスで、コンピューターのスタンバイ状態を解除できるようにする
   - **Magic Packet でのみ、コンピューターのスタンバイ状態を解除できるようにする**
3. 「詳細設定」タブで **Wake on Magic Packet** を「有効」にする(項目がある場合)。
4. **高速スタートアップを無効化する**(重要):
   コントロールパネル → 電源オプション → 「電源ボタンの動作の選択」→「高速スタートアップを有効にする」のチェックを外す。
   ※高速スタートアップが有効だと、完全シャットダウンからのWOLが効かないことが多い。
5. ✅ 完了目安: シャットダウン中もLANカードに通電し、パケットを監視している状態。

### ステップ4: 自動ログイン & 常駐設定(ターゲットPC)

1. `Win + R` → `netplwiz` → 対象ユーザーを選び「ユーザーがこのコンピューターを使うには、ユーザー名とパスワードの入力が必要」のチェックを外す(表示されない場合はレジストリの `DevicePasswordLessBuildVersion` を `0` に変更)。
2. Claude Desktop など遠隔操作に使うツールをスタートアップ(`shell:startup`)に登録する。
3. ✅ 完了目安: 電源が入るだけで、人が触らなくても自動的に通信待機状態になる。

> **セキュリティ注意**: 自動ログインはPCに物理アクセスされた際のリスクになります。自宅など安全な場所に置くPCに限定してください。

### ステップ5: WOL中継環境の構築(ルーター / 中継デバイス)

マジックパケットはブロードキャストのため、インターネットから直接は届きません。以下のどちらかを用意します。

- **方法A: ルーターにVPN(WireGuard等)を構築** — スマホからVPNで自宅LANに入り、LAN内と同じ要領でパケットを送る。ルーターが対応していればこれが最も安全でシンプル。
- **方法B: LAN内に常時起動の中継端末を用意** — Raspberry Pi や小型PCを常時起動しておき、外からSSH等で入ってこのリポジトリの `wol.py` を実行する。

✅ 完了目安: 外出先のスマホから自宅LANに安全に接続できる。

> ルーターのポート開放でUDPパケットを直接転送する方法は、セキュリティリスクが高いため非推奨です。

### ステップ6: 遠隔起動の実行(操作用スマホ)

- **VPN経由の場合**: スマホでVPN接続 → WOLアプリ(RemoteBoot、Wake On Lan 等)にMACアドレスを登録し、マジックパケットを送信。
- **中継端末経由の場合**: SSHクライアント(Termius等)で中継端末に接続し、`python3 wol.py --device desktop-pc` を実行。
- ✅ 完了目安: パケット着信をトリガーに、自宅PCがコールドスタートする。

## 動作テストの進め方(トラブル切り分け)

いきなり外出先から試すのではなく、段階的に確認するのがおすすめです。

1. **スリープからの復帰** を同一LAN内から試す(いちばん通りやすい)。
2. **シャットダウンからの起動** を同一LAN内から試す(ダメなら高速スタートアップ/BIOS設定を再確認)。
3. **VPN/中継経由** で外出先(スマホのテザリング等)から試す。

### うまくいかない時のチェックリスト

- [ ] 有線LANで接続しているか(Wi-FiはWOL非対応が多い)
- [ ] 高速スタートアップを無効にしたか(Windows)
- [ ] シャットダウン中にLANポートのランプが点いているか(消えていればBIOS設定か電源供給の問題)
- [ ] MACアドレスの控えが正しいか(`wol.py` は `:` `-` 区切りどちらでも可)
- [ ] VPN越しの場合、送信先IPをLANのブロードキャストアドレス(例: `192.168.1.255`)にしているか
- [ ] 電源タップ等でPCへの通電自体が切れていないか
